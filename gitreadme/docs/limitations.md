# AdaptiveLearn AI — Limitations

## 1. Overview

AdaptiveLearn AI is a hackathon MVP designed to demonstrate an end-to-end adaptive learning workflow.

The system demonstrates:

- Personalized learning paths
- Mastery-based progression
- Knowledge graphs
- Learning interest analysis
- Educational video recommendations
- Interactive learning missions
- AI-assisted learning
- Machine-learning learning-state prediction
- Facilitator interventions
- Career exploration
- Adaptive timetables
- Community learning

The following limitations should be understood when evaluating the MVP.

# 2. AI API Dependency

Possible limitations include:

- API availability
- API rate limits
- Network failures
