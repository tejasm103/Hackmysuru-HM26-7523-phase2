# AdaptiveLearn AI — Setup Guide

## 1. Project Overview

AdaptiveLearn AI is a Flask + MySQL + Vanilla JavaScript adaptive learning platform.

Technology stack:

- Python
- Flask
- Flask REST API
- MySQL
- HTML5
- CSS3
- Vanilla JavaScript
- Chart.js
- scikit-learn
- YouTube Data API v3
- Optional LLM API

The application supports Demo Mode and can run without external AI or YouTube API keys.

---

# 2. System Requirements

Before starting, install:

- Python 3.10+
- MySQL 8+
- Git
- VS Code or another code editor
- Modern web browser

Recommended:

- 8 GB RAM or more
- Stable internet connection for external API features
